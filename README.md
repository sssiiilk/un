# un. Portfolio

Сайт-портфолио студии `un.` для презентации digital-решений в сфере образования. Проект включает главную страницу, страницы кейсов, контактный блок и кастомные визуальные секции с анимированным фоном.

Проект собран на `React + Vite`, использует hash-маршрутизацию и хранит большую часть контента в одном файле данных, поэтому его удобно поддерживать и редактировать.

## Что есть в проекте

- главная страница с hero-блоком, кейсами, смысловыми секциями и контактами
- отдельные страницы кейсов
- анимированные фоны на базе `Velaris`
- адаптивная верстка для desktop и mobile
- единый файл с основным контентом и структурой кейсов

## Технологии

- `React 19`
- `Vite 8`
- `Tailwind CSS v4` через `@tailwindcss/vite`
- `motion` / `framer-motion`
- `lucide-react`
- глобальные стили в `src/index.css`

## Как устроены маршруты

В проекте используется hash-router из `src/lib/router.js`.

Основные маршруты:

- `#/` — главная страница
- `#/work` — переход к секции кейсов на главной
- `#/services` — переход к секции `Как мы работаем`
- `#/contact` — переход к контактам
- `#/work/<slug>` — отдельная страница кейса

Такой подход удобен для статического сайта и не требует сложной серверной настройки роутинга.

## Как редактировать контакты

Контакты на главной и часть общих данных находятся в `src/data/content.js`.

### Объект `site`

Содержит:

- `mark` — короткое имя бренда
- `name` — подпись бренда
- `email`
- `location`
- `telegram`
- `resumeUrl`
- `portfolioUrl`

### Массив `homeContacts`

Этот массив управляет карточками контактов на главной:

- подписью поля
- отображаемым текстом
- ссылкой

Пример:

```js
export const homeContacts = [
  {
    label: 'telegram',
    value: site.telegram,
    href: `https://t.me/${site.telegram.replace(/^@/, '')}`,
  },
]
```

## Как редактировать кейсы

Все кейсы находятся в массиве `cases` внутри `src/data/content.js`.

Каждый кейс — это объект с полями, которые управляют и карточкой на главной, и внутренней страницей.

### Основные поля кейса

- `slug` — адрес кейса
- `client` — название проекта
- `summary` — краткое описание на главной
- `image` — баннер карточки на главной
- `heroTitle` — большой заголовок в hero кейса
- `heroTags` — теги в hero
- `headline` — заголовок первого текстового блока
- `mood` — вводный текст
- `work` — список тезисов для блока слева
- `result` — текст правого блока
- `analysisTitle` — заголовок блока проблемы
- `analysis` — текст блока проблемы
- `finalTitle` — заголовок блока результата
- `finalResult` — текст результата
- `introMedia` — картинка или видео в первом медиа-блоке
- `featureImage` — широкий блок после проблемы
- `featureImageFit` — режим отображения изображения (`contain`, если нельзя обрезать)
- `gallery` — нижняя галерея изображений
- `meshBg`, `meshColors` — цвета фона `Velaris`

### Пример кейса

```js
{
  slug: 'modus',
  client: 'МОДУС',
  summary: 'Короткое описание кейса для главной.',
  image: '/cases/card2.png',
  heroTitle: 'МОДУС',
  heroTags: ['Концепция', 'Каталог программ', 'Приёмная кампания'],
  introMedia: '/cases/modus/desktop-modus.mp4',
  featureImage: '/cases/modus/problem-banner.png',
  gallery: [
    '/cases/modus/res-banner1.png',
    '/cases/modus/res-banner2.png',
    '/cases/modus/res-banner3.png',
    '/cases/modus/res-banner4.png',
  ],
}
```

## Как добавить новый кейс

1. Сложите изображения и видео в `public/cases/<slug>/`
2. Добавьте новый объект в массив `cases` в `src/data/content.js`
3. Укажите уникальный `slug`
4. Заполните тексты, теги и медиа
5. Проверьте кейс по адресу:

```text
#/work/<slug>
```

Новая отдельная React-страница для кейса не нужна: используется общий шаблон `CasePage`.

## Работа с изображениями и видео

Статические файлы лежат в папке `public/`.

Примеры:

- `public/cases/card1.png`
- `public/cases/sochi/miu.mp4`
- `public/cases/modus/problem-banner.png`

В коде такие файлы подключаются через путь без `public`:

```js
'/cases/modus/problem-banner.png'
```

## Шрифты

Шрифты подключены в `src/index.css` через `@font-face`.

Сейчас в проекте используются:

- `Vela Sans`
- `Tovar`
- `NauryzRedKeds`

Если нужно заменить или добавить шрифт:

1. положите файл в `public/fonts`
2. добавьте или обновите `@font-face` в `src/index.css`
3. при необходимости обновите CSS-переменные в `:root`

## Фон Velaris

Для анимированных фоновых секций используется компонент:

`src/components/ui/velaris.tsx`

Основные параметры:

- `bg`
- `colors`
- `speed`
- `grain`
- `vignette`
- `height`

Через эти пропсы можно настраивать hero главной, фон кейсов и узкие цветовые полосы между секциями.

## Адаптивность

Основные брейкпоинты лежат в `src/index.css`:

- `@media (max-width: 860px)`
- `@media (max-width: 720px)`
- `@media (max-width: 560px)`

Если дорабатываете мобильную версию, в первую очередь проверяйте:

- хедер и мобильное меню
- карточки кейсов на главной
- секцию `Как мы работаем`
- текстовые блоки кейсов
- широкие баннеры и галереи
- CTA-кнопки
